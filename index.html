Generador de Actas de Entrega

Completa los datos de la unidad y del cliente, y descarga el Acta de Entrega ya formateada en Word, lista para imprimir y firmar. Funciona para departamentos y para estacionamientos.

Los campos vienen precargados con un caso de ejemplo. Bórralos o sobrescríbelos para generar el acta de cualquier otro cliente. El nombre del archivo se arma solo, a partir del tipo de unidad, el número y el proyecto.
